# Security policy

RustPS5Emu runs game code natively on your machine with the rights of your user account. Only run games you dumped yourself, from sources you trust.

To report a security problem in the emulator (for example a game or a shared shader-cache file that can escape the emulator or write outside its data folders), please do not open a public issue. Use GitHub's private vulnerability reporting ("Report a vulnerability" on the Security tab of https://github.com/keklick1337/rps5e) instead. You will get an answer within a few days.

Fixes go into `master` (the development branch) and ship with the next tagged release.
