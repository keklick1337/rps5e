## Source

`PS5-3.20_Libs` (39158 entries in 275 modules, 31275 distinct NIDs) is the genstub.py output for firmware 3.20: one `.c` per system module, `sprx_dlsym(handle, "<NID>", &__ptr_<name>)` per export.

- 39158 of 39158 entries have NID = SHA1(name + salt): names and NIDs are right.
- Only exports with a known name are listed; the firmware exports more (unnamed NIDs are dropped), so the totals are a lower bound.
- It is firmware 3.20: functions added later are missing (game imports outside the list above).
- Per module, not per library: libkernel mixes libkernel, libScePosix and the other libraries of the module; libkernel_sys/_web, libSceNKWebKit (libSceJsc), libSceAgcVsh (libSceAgc) re-export others.
- Data symbols are listed like functions; modules games ship themselves (libc.prx, middleware) are not in it.
- Against our NID catalog (`crates/ps5nid/data/merged_exports.tsv`, 76323 entries): 31275 (NID, module) pairs agree; 0 firmware NIDs are missing from it (7883 module re-exports are filed there under one library only); the catalog has these entries the firmware list does not:

  - 44098: library name that is no firmware module (aliases, game modules)
  - 943: named export the 3.20 list does not have (newer firmware)
  - 7: NID is not SHA1(name): placeholder or wrong name
